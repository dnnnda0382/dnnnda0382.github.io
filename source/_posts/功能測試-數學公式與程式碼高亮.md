## 一、數學公式

公式是在 build 階段由 `@renbaoshuo/markdown-it-katex` 直接算成 HTML 的，瀏覽器不需要跑 JS 就能看到結果，所以載入很快、也不會有「先看到原始碼再跳成公式」的閃爍。

### 1.1 行內公式

用單個 `$` 包起來。質能等價是 $E = mc^2$，畢氏定理是 $a^2 + b^2 = c^2$，而 $\sqrt{3x-1}+(1+x)^2$ 這種也沒問題。

希臘字母與下標：$\alpha, \beta, \gamma, \Delta, \sum_{i=1}^{n} x_i, \lim_{x \to 0} \frac{\sin x}{x} = 1$。

### 1.2 區塊公式

用兩個 `$$` 包起來，會置中並使用較大的符號。

高斯積分：

$$
\int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}
$$

多行對齊（`aligned` 環境）：

$$
\begin{aligned}
d & = ax + by \\
  & = by + (a \bmod b)x \\
  & = by + \left(a - \left\lfloor \frac{a}{b} \right\rfloor b \right)x \\
  & = ax + b\left(y - \left\lfloor \frac{a}{b} \right\rfloor x\right)
\end{aligned}
$$

矩陣與分段函數：

$$
A = \begin{pmatrix}
1 & 2 & 3 \\
4 & 5 & 6 \\
7 & 8 & 9
\end{pmatrix}
\qquad
f(x) = \begin{cases}
x^2 & \text{if } x \geq 0 \\
-x  & \text{otherwise}
\end{cases}
$$

組合數與極限：

$$
\binom{n}{k} = \frac{n!}{k!\,(n-k)!}
\qquad
e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n
$$

### 1.3 不會被誤判成公式的情況

依照 pandoc 慣例，`$` 右邊緊接空白、或左邊緊接空白時不會被當成公式，所以寫金額是安全的：這台電腦要 $1,200 美金，那台只要 $980 美金。

## 二、程式碼高亮

程式碼同樣是在 build 階段用 prismjs 上色（`preprocess: true`），前端不需要載 highlight 的 JS。

### 2.1 C++

```cpp
#include <iostream>
#include <vector>

// 二分搜尋：回傳第一個 >= target 的位置
int lower_bound_idx(const std::vector<int>& a, int target) {
    int lo = 0, hi = a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

int main() {
    std::vector<int> v{1, 3, 5, 7, 9};
    std::cout << lower_bound_idx(v, 6) << std::endl;  // 3
    return 0;
}
```

### 2.2 Python

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n: int) -> int:
    """計算費氏數列第 n 項。"""
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(10)])
```

## 四、注意事項：LaTeX 與 Hexo 的大括號衝突

Hexo 在渲染 Markdown 之前會先跑一層 Nunjucks 模板引擎，它會把**連續兩個左大括號**當成模板變數語法。所以公式裡如果出現連續兩個左大括號（例如巢狀的 `\frac` 分子），**整個 build 會直接失敗**，錯誤訊息長這樣：

```
FATAL Nunjucks Error: _posts/你的文章.md [Line 2, Column 275] expected variable end
```

**解法：在兩個大括號中間加一個空白。** LaTeX 在數學模式會忽略空白，所以渲染結果完全一樣，但 Nunjucks 就不會誤判了：

$$
\frac{ {x}^{2} }{y} + \sum_{ {i}=1 }^{n} a_i
$$

上面這條公式的原始碼寫的是 `\frac{ {x}^{2} }{y}`（兩個左大括號中間有空白），而不是擠在一起的寫法。

> ⚠️ 網路上常見的建議是用 Hexo 的 `raw` 標籤把公式包起來。**這招對數學公式沒有用**——`raw` 標籤的內容會被抽換成佔位符、跳過 Markdown 渲染階段，等於 KaTeX 根本看不到那段公式，最後會原封不動吐出 LaTeX 原始碼。加空白才是正解。

一般的公式（沒有連續兩個左大括號）完全不用管這件事。
